Module: PIM
Submodule: Employee List
Priority: Medium

Preconditions
User is logged in with valid credentials

User has navigated to PIM > Employee List

At least one employee exists in the list

Test Steps
Scroll down to the Employee List table

Locate the target employee (e.g., Jane Smith)

In the Actions column, click the Edit button

Verify the Personal Details page opens

Update one or more fields (e.g., change Marital Status, update Driver’s License Number, edit Date of Birth)

Optionally navigate to other tabs in the sidebar (e.g., Job, Salary, Qualifications) and make changes

Click Save

Expected Result
The updated details are saved successfully

User remains on the employee’s Personal Details page

Changes are reflected correctly when the employee record is re-opened

Test Data
Employee: Jane Smith

Updated Marital Status: Married

Updated License Number: DL-987654

Updated Date of Birth: 1990-05-15
